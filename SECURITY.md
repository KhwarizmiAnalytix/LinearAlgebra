# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities. Instead, report
them privately via [GitHub Security Advisories](../../security/advisories/new) for this
repository, or email licensing@xsigma.co.uk with a description of the issue and steps to
reproduce.

We'll acknowledge reports within a few business days and follow up with a fix timeline.

## Supported versions

This project does not yet publish tagged releases; security fixes are made against the
`main` branch.
